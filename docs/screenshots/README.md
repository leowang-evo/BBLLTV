# README 界面截图

本目录只保存用于项目首页的 PNG 截图。账号头像及“用户”标签、本机继续观看记录、直播关注列表已在截图前以不透明遮罩覆盖；保存后的图像不包含这些区域的原始像素。

未选用个人动态、收藏、历史、账号详情、登录二维码和设备信息页面。视频作者与直播主播的公开名称属于内容本身，不是登录账号资料。
