# 141 版性能与设置

## 比较条件

基线保留 140 版业务实现，只添加同签名的非调试 benchmark 构建与 profileable 标记。处理了既有资源的 lint 兼容：逐配置检查样式继承链无环后，仅标记十处上游样式命名误报；为仅有横屏版本的时钟布局补充默认资源。两个比较包都使用版本码 141、同一包名和签名，关闭代码压缩，以便覆盖安装并保留数据。APK 哈希区分基线和优化版。

同一电视按相同顺序做暖缓存横移、下翻/上翻、实际播放中开关菜单，分别记录 gfxinfo 与内存；进程冷启动共三次，不清除磁盘缓存。帧统计不等于视频解码丢帧；一次操作序列不构成所有内容和长时间使用的性能保证。最终结果和原始日志在交付目录的本版验证记录中保留。

## 性能调整

- 主导航只创建当前栏目，其他栏目首次进入时创建；本机数据缓存首次读写时在原有 IO 线程初始化；默认头像直接显示本机资源，避免为占位图初始化图片管线。
- 首页推荐、热门及番剧/影视页只在进入可见生命周期后开始首次加载。保留现有缓存、刷新、分页和栏目入口，取消启动时旁页抢占网络、绑定和图片任务。
- 封面按视图居中裁剪，用 API 21 轮廓完成圆角，移除每张封面的位图变换副本。头像沿用原圆形变换。
- DiffUtil 对封面未变的内容使用局部绑定，更新标题、统计和作者，不重启已有封面请求。回收卡片清理图片请求和焦点缩放状态。
- Glide 通过公开模块接口延迟应用内存策略：普通设备资源缓存最多 12 MiB、位图池 4 MiB；低内存设备使用更小预算。Glide 自身继续处理系统内存回调。
- 复用计数格式器，跟随语言环境更新，近期发布时间不创建日期对象。与基线源码对照中文、英文、德文和阿拉伯文的数值及日期边界。
- 播放器销毁时清除播放器绑定、弹幕并移除子视图，使绘制资源尽早脱离窗口。原播放、字幕、选集和返回逻辑保留。

## 设置界面

分类和设置行使用深色卡片、淡紫焦点描边、当前值标签和统一间距。全部三十一个选择入口使用自有电视弹窗，取代系统列表：圆角面板、可滚动选项、当前值标记、默认聚焦当前值，返回取消并恢复原行焦点。兼容数值格式及单位差异，如 1.00/1.0 和 10s/10。消息弹窗使用同一风格。指针和遥控器都经过检查。

原选项数组、偏好键、权限处理及回调沿用；未配置更新源仍明确显示状态。设置检查只临时修改倍速并恢复，不执行清缓存、切换主题、退出登录或消耗硬币。

## 功能验证

新的局部绑定检查验证可见标题更新且封面请求身份不变；既有刷新/菜单/返回、遥控器、首页、真实媒体、选集、字幕、互动、续播和迟到响应分组回归。设置检查覆盖打开、默认焦点、返回取消、实际保存、跨进程保留与恢复。网络接口单独使用本机假账号服务验证。

独立源码隔离构建支持 `--variant benchmark`，对应 AGP 编译、DEX、原生库和公开依赖输入分别审计。交付保持原资源 ID，独立构建与实际测试构建比较全部非签名条目。API 21 静态检查与真实 Android 11、armeabi-v7a 电视功能检查分开记录。
