# BBLLTV v0.2.144

BBLLTV 首次公开发布，提供整理后的完整源码及 144 版 APK。

## 本版内容

- 更新 BBLLTV 启动图标、圆形/自适应图标、电视横幅和关于页图标。
- 关于页补充原项目、新项目地址与原作者致谢。
- 保留推荐、热门、分区排行、番剧影视、搜索、动态、直播和账号功能。
- 保留此前的首页增量刷新、遥控器焦点、长列表浏览和播放器菜单改进。
- 首页内容区按返回先回到顶部栏目；影视索引首次进入从首行开始，详情返回保留浏览位置。
- README 包含 9 张界面预览，账号入口、继续观看及直播关注信息已遮盖。

## 下载与安装

- `BBLLTV-v0.2.144.apk`：通用 APK，包含 32 位 ARM、64 位 ARM、x86 和 x86_64 原生库。
- `BBLLTV-v0.2.144-source.zip`：与本次提交对应的源码、README 和构建脚本，不含签名私钥。
- `SHA256SUMS.txt`：附件 SHA256 校验值。

APK 的包名为 `com.damon.bblab`，versionCode 为 `144`，为非调试验证构建，沿用此前验证包的签名，可覆盖同签名的旧版安装。仓库默认自行编译的包名为 `com.damon.bblab.standalone`，使用本机生成的调试签名，与本附件的签名不同。

## 验证范围

144 版已在 Android 16 模拟器完成 10 项针对图标、关于页、设置入口、返回及安装包一致性的检查。整理后的公开源码已在不携带原 APK、旧编译产物及签名私钥的目录重新编译并通过构建输入审计，新构建与本次 APK 的 1580 个非签名内容条目逐项一致。此前的业务和电视验证记录随源码保留；本版没有重新执行全部业务回归或新的电视性能对比。

## 使用范围

>
