# 140 版交互优化

本轮限于增量刷新、菜单减层和返回逻辑。保留账号、播放、直播、选集、字幕、画质、音频、弹幕、搜索和个人页面功能；不扩展本机“继续观看”，不连接电视或测量电视性能。

## 增量刷新

推荐、热门和排行榜的普通视频网格使用 `VideoListUpdates`。后台线程计算 DiffUtil 差异，主线程提交最新一代结果；相同渲染内容不触发通知，避免整页重新绑定。卡片内容快照与可变业务模型分开保存，不能以引用相同推断画面没有变化。

视频身份优先使用 EP、BV、AV 标识；重复身份附加出现序号。刷新、重排时恢复同一视频和纵向偏移，原卡片被删除时选择最近的剩余位置。用户已将焦点移到导航栏或其他控件时，迟到的焦点恢复不抢占输入。显式刷新回到顶部，后台更新不强制回顶。

待提交的替换列表作为随后分页的基础，避免异步刷新与追加相互覆盖。加载更多占位行与数据差异分别通知。推荐、热门及排行榜的首屏请求使用代际检查，新的刷新使旧请求失效；页面释放也会取消待提交差异。缓存只补充尚未收到新内容的首屏。历史和搜索的专用行保持原绑定逻辑。

## 菜单减层

弹幕开关、顶部弹幕和底部弹幕在原行按确认直接切换，并以开关和文字显示状态，焦点留在该行。透明度、字号、速度等数值仍使用选项列表。画质、倍速、字幕、编码、音质及比例进入时聚焦当前可选项；偏好值不在当前媒体可选范围时聚焦第一个可用值。父菜单仍恢复原焦点。

原十五个播放器操作入口保留。“从头播放”作为第十六个可选操作，在点播时显示，直播时隐藏；触发后从当前视频或分集零秒开始并播放，不改变当前媒体类型、画质或分集。循环/续播设置继续使用原入口。

## 返回逻辑

1. 设置选项列表返回上一层；设置主面板返回播放控制区。
2. 推荐/相关内容覆盖层先关闭自身。
3. 控制区可见时先隐藏控制区，继续播放。
4. 控制区隐藏时再按返回退出播放，并恢复来源页面的卡片焦点及位置。

从历史进度进入播放时仅提示已续播，返回键不再触发从头播放。播放页不再要求双击返回退出；首页原有的防误退提示保持不变。UI 状态版本迁移只丢弃旧控件状态，保留账号与设置。

账号入口等待正在进行的在线校验完成，再打开账号资料或登录页面，避免冷启动时把尚未确认的状态当作未登录。等待期间按返回会取消这次打开请求；校验失败保留原有错误提示，不清除登录数据。

## 验证方法

`tools/verify_player_remote.py --refresh-navigation` 在实际首页和真实点播中检查：无变化零通知、单卡内容更新、插入/重排的身份及位置、删除焦点回退、导航焦点不被抢占、并发替换与追加、占位行一致性、卸载取消、菜单当前值、开关原地切换、实际从头解码、直播隐藏重播，以及逐层返回和来源焦点。

原遥控器探针检查所有十六个可选按钮同时显示的完整范围与方向键路径。首页、真实点播/直播、字幕、多 P、番剧、互动视频、操作弹窗、续播模式、迟到响应、榜单、账号只读页面、搜索和设置分别回归。最终执行结果与边界在交付目录 `dist/VALIDATION.md` 记录；旧版电视性能数据不能替代本版电视验证。
