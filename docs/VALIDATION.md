# 138 版补测与修复记录

2026-11-12，在已登录的 Android 11、32 位雷鸟电视与 Android 16 arm64 模拟器继续验证。137 版记录保存在 `VALIDATION-137.md`。工程可独立源码编译，不声称逐字恢复原开发者源码。

## 五个榜单

音乐、游戏、知识、美食、纪录片在电视登录态及模拟器扫码登录后均返回内容、绑定页面且能接收焦点：前四个各 100 条，纪录片 73 条。前一轮五项不再作为登录态加载失败项。

匿名模拟器复现了同一接口先成功、随后返回 `-352`，包括原本能返回 100 条的音乐与游戏。这是本轮观察到的服务端请求限制；没有证据说明五个分区 ID 均失效，也不能保证匿名接口始终可用。修正排行榜的 WBI 签名与来源页面后，匿名态仍观察到受限；不能声称签名修正消除了服务端风控。扫码后五项通过。

## 实际修复

- 排行榜采用 WBI 参数，按接口保留明确的来源页面；请求拦截器不再覆盖调用方已声明的来源。
- 修正 WBI 对原始值的处理：保留小数点、逗号与加号，中文和特殊字符按 URI 规则编码，时间戳参与排序，重复签名排除旧签名。加入独立固定向量与本机 HTTP 检查。
- 多 P 与番剧选集模式对应错误会造成类型转换崩溃；改用明确的模式常量，验证了真实多 P 选集与番剧数据的选集入口。
- 收藏状态查询改用数字 aid；只有 BV 号时先解析视频元数据。原实现错误地把 BV 号当作 aid 请求。
- 格式能力与默认清晰度分开声明，初始请求提供全部常用 DASH 格式能力，画质/音轨菜单可以展示服务端允许的高级选项。
- 按服务端确认的清晰度筛选视频轨道，再选择编码，修复请求 HDR 却可能选中同编码 SDR 流的问题。
- “当前列表下一个”在队列耗尽时停止，不再误播推荐视频；推荐模式、剧集模式、禁用模式与手动切换保留各自路径。
- 播放元数据回调检查页面是否仍然有效，修复快速退出后迟到响应更新已卸载 Fragment 的崩溃。
- 番剧迁移到带签名的 Web v2 播放接口，解包 `result.video_info`；保留权限错误、空流及 `v_voucher`，验证重试回到对应播放类型。修复成功切到下一集后仍执行“播完退出”的逻辑。

## 边界

- 匿名请求仍可能返回 `-352`；番剧旧接口 `-351` 已通过迁移新版播放接口解决，未改动账号 Cookie 或模拟设备指纹。匿名榜单受限结果保留，不计为内容加载通过。
- 高级媒体为抽样真实解码；没有 8K 显示设备，也没有逐一覆盖所有影片、音轨、互动图或自动续播组合。杜比解码通过不能证明外接音响的 Atmos 位流透传效果。
- 本轮实际账号写入未执行，尤其投币与三连会消耗硬币；本机假账号服务的集成结果在此单独标明。
- 历史测试中失败的探针和修复前崩溃日志保留用于溯源；最终结果以最终包回归报告为准。
