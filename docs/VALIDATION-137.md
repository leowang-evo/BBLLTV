# 137 版重构与验证记录

本轮在 2026-11-11 至 12 完成。程序为功能重建与重构工程，保持独立源码编译，不声称逐字恢复原开发者源码。

## 改动

- 132 个应用类按职责命名、分包。页面生命周期、分页、导航、列表绑定、账号状态和播放协调的主要接口与字段改为可读名称。升级迁移旧 Fragment 保存状态，保留账号数据。
- 播放控件有明确的初始焦点、左右顺序和进度条上下路径。内层视频组件只渲染，焦点由外层和应用控件处理；覆盖控件隐藏、动画及仅显示进度条时的唤出。
- 列表只执行最新的异步焦点请求；设置统一选项渲染与返回栈，保留发起选项。修复动画结束抢焦点、容器焦点点击崩溃、返回事件抬起后继续传播的问题。
- 暂停时手动打开的控件保持显示，恢复播放后恢复隐藏计时。保留双击快进及取消逻辑。
- 67 处相同网络转发回调合并为类型化实现。业务失败与空响应有明确处理；分区受限不再空白。搜索分类使用现有签名接口，统一分页、过期响应丢弃、空态和手动重试。
- 修正动态列表去重与插入通知范围，移除两个无引用的生成残留类型。更新关于页和构建版本文案。

## 尚未覆盖或受外部条件限制

- 模拟器匿名态的音乐、游戏、知识、美食、纪录片五个榜单未验证到内容加载；其中已观察到服务端 `-352` 及正确的受限提示、重试按钮。这五项未计为通过。
- 实际字幕文件显示、互动视频分支、全部切集/自动续播内容组合、4K/HDR/杜比及所有高码音频未用真实内容逐一覆盖。字幕索引边界与选项回调有组件检查。
- 本轮没有重新用手机完成扫码确认；验证了二维码生成、查询及已有登录保持。账号写操作与投币未验证实际服务端结果。
- 页面自动化在播放状态下有控件隐藏与事件时序干扰。暂停、跳转、恢复、编码及画质的结论采用真实播放器状态检查，不将界面树读取失败算作应用功能失败。

