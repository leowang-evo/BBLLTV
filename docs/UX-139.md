# 139 版首页与播放器体验调整

## 首页

- 保留推荐、热门、番剧、影视与四列内容布局，侧栏沿用原来六个功能入口、账号和设置，补充文字标签。
- 深色主题使用蓝黑底色；卡片标题减轻字重，保留两行空间，次要信息更安静。浅色及其他主题继续使用现有主题属性。
- 焦点使用描边及 1.025 倍、140 ms 的视图变换，不改列表尺寸。首页关闭批量刷新时的移除和插入淡入动画，缓存限制为八个列表项。
- 从子页面返回时恢复原卡片焦点及 LayoutManager 滚动锚点，避免侧栏隐藏引起宽度变化后位置漂移。
- 本机缓存迟到时仅填充空列表，不再替换新网络数据和清除焦点。

## 本机继续观看

`platform/ContinueWatching` 只保存当前账号最后一条有效、未完成的点播记录，采用毫秒进度，包含 aid、bvid、cid、sid、epid 及简要展示字段。多 P 和番剧保留分集身份。它不要求额外网络请求，也不替换“我的/历史”的服务端历史列表。

播放少于三秒不保存；距已知片尾五秒内的同一分集清除续播入口；未知时长仍可保存。直播及无效播放身份不写入。损坏记录视为空记录。首页恢复显示时刷新入口，点击直接按原播放流程请求媒体并恢复进度。

## 播放器

- 沿用原来十五个按钮 ID、显示条件、点击回调与遥控器焦点顺序，包含选集、字幕、弹幕、循环、直播及互动入口。
- 标题、时间、进度条与操作区分层，进度时间移到标题右侧，避免十五个可选按钮同时可见时互相挤压。
- 按钮聚焦后显示操作名称，底部摘要使用实际已选择画质及播放器速度。
- 设置面板从 650 缩窄到 560 设计像素，调整文字层级和行距。焦点描边与当前选项勾选分别显示。
- 抽屉动画 180 ms，移动距离按面板及返回按钮宽度计算。保留原有返回栈、焦点恢复及播放/暂停行为。
- 字幕关闭、不可用与已选语言的菜单值同步刷新，避免保留过期语言名。

## 验证方法

API 21 NewApi lint 和独立源码构建用于静态兼容验证。Android 16 arm64 模拟器运行首页探针、播放器遥控器及设置探针、真实字幕/多 P/番剧/互动/弹窗/续播/生命周期和点播直播检查，以及目录、已登录账号读取和设置页面脚本。结果及证据随最终 APK 一起保存。

真实播放会正常更新观看历史；账号写操作不用于本轮 UI 回归。会员格式、32 位实机性能及服务端限流不能由模拟器界面检查证明。138 版的实机记录独立保留，不作为本轮已经在电视安装的声明。

播放顺序的回归检查使用真实循环行为：先断言按钮切换播放器的 repeat mode，再跳到片尾，等待实际播放回到开头。旧探针将此按钮误当成“立即重新播放”，曾出现假失败；修正后的检查与原按钮功能保持一致。

直播清晰度探针等待弹窗取得真实输入窗口焦点后再发送按键，并同时检查清晰度状态、刷新后的地址列表及实际解码，避免仅凭列表已经拥有视图焦点就开始操作。

最后补充：加载图标仅在播放器 BUFFERING 状态显示；焦点仍在播放键时，暂停/播放名称立即同步。首页区分从卡片和从“继续观看”进入的返回目标，续播退出后回到入口。首页探针还会临时保存一个真实视频的 12 秒进度，实际点击续播、解码、核对 CID 和进度增长，然后检查返回焦点并清理独立测试键。
