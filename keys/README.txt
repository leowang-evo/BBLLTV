No signing private key is distributed with this source tree.

A fresh checkout uses the per-machine Android debug keystore generated by AGP.
The default application ID is com.damon.bblab.standalone.

An existing private local keys/reconstruction-debug.keystore may be retained by its
owner to sign upgrades for a prior validation installation. It is ignored by Git
and excluded from source exports. Its local validation convention uses the alias
androiddebugkey and Android's standard debug passwords.

For a prior com.damon.bblab installation, matching package ID and signing key are
both required to preserve data during an upgrade. Do not publish the key.
Configure and securely retain your own signing key for maintained distribution.
